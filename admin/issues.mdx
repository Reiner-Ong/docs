An <Tooltip tip="A fault or problem reported against one lift and tracked until it is closed." cta="Read the glossary" href="/start/glossary#issue-fault">issue</Tooltip> records one problem against one <Tooltip tip="The physical elevator unit at a building." cta="Read the glossary" href="/start/glossary#lift">lift</Tooltip>. It stays **Open** until your team resolves or closes it.

<Note>
  Before you start, sign in to the admin dashboard and make sure the lift exists in Portfolio. If it does not, [add the lift](/admin/lifts) first. These steps are for the web dashboard; the mobile app uses a different flow.
</Note>

<Note>
  Owners, Admins, and Technicians can raise, edit, and close issues in the web dashboard. Call Centre users can view issues but cannot change them.
</Note>

## Raise an issue

<Steps>
  <Step title="Open the Issues tab">
    In the left sidebar, select <Tooltip tip="The dashboard area where your LiftAuth company keeps its buildings, Building Manager records, lifts, and issues together." cta="Read the glossary" href="/start/glossary#portfolio">Portfolio</Tooltip>. Then select **Issues**.
  </Step>
  <Step title="Select Raise Issue">
    Select **Raise Issue** in the top-right corner.
  </Step>
  <Step title="Choose the lift and severity">
    Select the lift with the problem. Then choose how urgently it needs attention:

    - **Critical** — there is an immediate safety risk, or the lift cannot be used now.
    - **Major** — the lift can still be used, but the problem affects normal operation and could take it out of service soon.
    - **Minor** — the problem is cosmetic or has little immediate impact and can wait for a planned visit.
  </Step>
  <Step title="Describe the problem">
    Enter a short, specific **Title**. The lift and title are required. The **Description** is optional, but it helps the next person understand what happened, where it happened, and anything already tried.
  </Step>
  <Step title="Add photos or videos">
    Add clear photos or videos when they will help someone understand the problem. This is optional.

    <Tip>
      You can add up to 10 files. Photos can be JPEG, PNG, or WEBP files up to 10 MB each. Videos can be MP4 or MOV files up to 64 MB each, with no more than 5 videos.
    </Tip>
  </Step>
  <Step title="Raise the issue">
    Select **Raise Issue**. The issue appears in the **Open** list with its own reference, such as **ISS-2026-0001**. The reference is the unique number you can use when discussing that issue.
  </Step>
</Steps>

<Tip>
  If you are already viewing a lift, open its **Issues** tab and select **Raise Issue**. LiftAuth fills in the lift for you.
</Tip>

## Find an issue

Open **Portfolio**, then select **Issues**. The page shows open issues first.

There is no search box on this page. Use the controls above the list to narrow it down:

- show **All**, **Open**, or **Closed** issues;
- filter by **Critical**, **Major**, or **Minor** severity; and
- sort by the date the issue was raised.

Each row shows the issue reference, title, lift, and building. Select an issue to open it. If the list has more than one page, use the page controls at the bottom.

## Update an open issue

1. Open the issue from the **Issues** list.
2. Select **Edit Issue**.
3. Change the title, description, or severity. You can also add new photos or videos, or remove existing ones.
4. Select **Save Changes**.

<Warning>
  You cannot edit an issue after it is closed.
</Warning>

## Close an issue

Close an issue when no more work needs to be tracked against it.

<Steps>
  <Step title="Open the issue">
    Find the issue in **Portfolio** → **Issues**, then select it.
  </Step>
  <Step title="Select Close Issue">
    Select **Close Issue** on the right side of the page.
  </Step>
  <Step title="Choose a reason">
    Choose the reason that best describes what happened:

    - **Resolved** — the problem was fixed.
    - **Won't Fix** — the problem is known, but no work will be done.
    - **Duplicate** — the same problem is already recorded as another issue.
    - **Decommissioned** — the lift was taken out of service.
  </Step>
  <Step title="Confirm">
    Select **Close Issue**. The issue moves to the **Closed** list and can no longer be edited.
  </Step>
</Steps>

Closing an issue does not change the lift's status. A closed issue cannot be reopened. If the same problem returns, raise a new issue.

<Note title="Issues resolved during a job">
  A technician can link an open issue to a <Tooltip tip="A service visit to a lift." cta="Read the glossary" href="/start/glossary#job">job</Tooltip> in the mobile app. Submitting the linked issue as **Resolved** closes it automatically. Submitting it as **Not Resolved** leaves it open.
</Note>
